# Devpost Auto-Filler

A minimal Chrome extension scaffold that logs when Devpost pages load.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Build the extension:
   `npm run build`
3. Load the `dist/` folder as an unpacked extension in Chrome.
